Configuration requise

Connecte ton projet Supabase

Ce site utilise Supabase (base de données + authentification, gratuit) pour que les comptes et les annonces fonctionnent une fois déployé sur Vercel. Il ne reste que 2 informations à renseigner dans le fichier :

  1. Crée un projet gratuit sur supabase.com
  2. Dans Project Settings → API, copie ton Project URL et ta clé anon public
  3. Ouvre le fichier index.html, cherche SUPABASE_URL et SUPABASE_ANON_KEY tout en haut du script, et colle tes valeurs
  4. Exécute le script SQL fourni dans l'éditeur SQL de Supabase pour créer les tables

Le guide complet t'a été envoyé à côté de ce fichier.
